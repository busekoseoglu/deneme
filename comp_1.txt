# %% [TEŞHİS] - TEMMUZ vs AYLIK MİNİMUM (agent bazında, ana modele dokunmaz)
from ortools.sat.python import cp_model as _cm
from datetime import timedelta as _td

assert gecmis_calisma_gunleri, "gecmis_calisma_gunleri BOŞ - İŞLEME'yi Temmuz yüklü çalıştır, test hücresini kaldır."

_plan = sorted({pd.to_datetime(ds).date() for ds in PLAN_GUNLER})
_resmi = globals().get("resmi_tatil_date_set", set()) or {pd.to_datetime(d).date() for d in RESMI_TATIL_GUNLERI}
_is_dates = {d for d in _plan if d.weekday() < 5 and d not in _resmi}
_aylik_is = len(_is_dates)
_hamile_sut = set(df_tam.loc[
    (pd.to_numeric(df_tam["hamile_flg"], errors="coerce").fillna(0).astype(int) == 1) |
    (pd.to_numeric(df_tam["sut_izni_flg"], errors="coerce").fillna(0).astype(int) == 1),
    "agent_user_code"].astype(str).str.strip())

_sorunlu = []
for a_raw in AGENTS:
    a = str(a_raw).strip()
    tipd = tip_map.get(a, {})
    izin_is = len({d for d, t in tipd.items() if str(t).strip().lower() == "izin" and d in _is_dates})
    baz = _aylik_is - izin_is
    if baz <= 0:
        continue
    jgun = gecmis_calisma_gunleri.get(a, set())

    m = _cm.CpModel()
    w = {}
    yasak = 0
    for d in _plan:
        tip = str(tipd.get(d, "")).strip().lower()
        hard_off = tip in ("izin", "off_t", "off_t2")
        hs_ban = (a in _hamile_sut) and (d.weekday() in (5, 6))
        if hard_off or hs_ban or d in _resmi:
            w[d] = None; yasak += 1
        else:
            w[d] = m.NewBoolVar(f"w_{d}")

    ws = _plan[0] - _td(days=WINDOW_DAYS - 1)
    son = _plan[-1] - _td(days=WINDOW_DAYS - 1)
    d = ws
    while d <= son:
        wd = [d + _td(days=k) for k in range(WINDOW_DAYS)]
        avars = [w[x] for x in wd if x in w and w[x] is not None]
        if avars:
            jc = sum(1 for x in wd if x in jgun)
            m.Add(sum(avars) <= max(0, MAX_CONSECUTIVE_WORK_DAYS - jc))
        d += _td(days=1)

    calis = [w[d] for d in _plan if w[d] is not None and d not in _resmi]
    m.Maximize(sum(calis))
    sol = _cm.CpSolver(); sol.Solve(m)
    max_work = int(sol.ObjectiveValue())
    if max_work < baz:
        _sorunlu.append({"agent": a, "baz_gereken": baz, "max_calisabilir": max_work,
                         "eksik": baz - max_work, "temmuz_gun": len(jgun), "yasak_gun": yasak})

print(f"Aylık-min'i Temmuz altında SAĞLAYAMAYAN agent: {len(_sorunlu)}")
if _sorunlu:
    display(pd.DataFrame(_sorunlu).sort_values("eksik", ascending=False))
